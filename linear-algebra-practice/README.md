# 선형대수 5장(직교) 문제집 생성기

고등학생 선형대수 5장(직교여공간, 정사영, 그램-슈미트, QR 분해, 대칭행렬의 직교대각화, 스펙트럼 정리/분해) 시험 대비용입니다.

- `generator.py`: 손으로 풀기 좋은 숫자가 나오는 문제를 시드(seed)로 재현 가능하게 무작위 생성하고, HTML 문제집을 만듭니다.
- `verify.py`: 모든 문항의 정답을 SymPy로 **정확히**(부동소수점 없이) 검산합니다. 검산에 실패한 문항은 문제집에 절대 실리지 않습니다.
- `index.html`, `set-2.html`, `set-3.html`: 생성된 문제집 3세트(시드 1, 2, 3, 각 48문항). 각 문제 아래에 **정답**과 **단계별 풀이**가 접혀 있습니다.

GitHub Pages 주소(배포 시): `https://kimgshskim-prog.github.io/game-shelf/linear-algebra-practice/`
모든 링크는 상대 경로라서 폴더째 어디에 올려도 동작합니다. 그냥 `index.html`을 브라우저로 열어도 됩니다(수식 렌더링을 위해 인터넷 연결 필요).

## 준비

Python **3.12 이상**과 SymPy가 필요합니다. 코드가 3.12에서 새로 생긴 f-string 문법을 씁니다.

```bash
pip install sympy
```

## 사용법

```bash
cd linear-algebra-practice
python generator.py --seed 1 --count 40          # index.html 한 장 (40문항: 유형별 5문항)
python generator.py --seed 7 --count 48 --out my-set.html
python generator.py --seed 1 --count 48 --sets 3  # 지금 커밋된 3세트를 다시 만드는 명령
```

| 옵션 | 뜻 |
|---|---|
| `--seed` | 난수 시드. 같은 시드면 항상 같은 문제집이 나옵니다. |
| `--count` | 세트당 총 문항 수. 8개 유형에 고르게 나눕니다(기본 48 → 유형별 6). 40 이상이면 유형별 5문항 이상. |
| `--sets N` | N개 세트를 시드 `seed, seed+1, …`로 만들어 `index.html`, `set-2.html`, …에 저장하고, 페이지끼리 링크합니다. |
| `--out` | 세트가 1개일 때 저장할 파일 이름(기본 `index.html`). |

## 검산

```bash
python verify.py                      # 시드 1~20 세트(각 48문항)를 만들어 전부 검산
python verify.py --seeds 1-100        # 더 많은 시드로 테스트
python verify.py --check-html         # 커밋된 index.html / set-*.html 이 생성기 출력과 똑같은지도 확인
```

실패한 문항이 있으면 종료 코드가 1입니다. "생성 단계에서 걸러진 후보"는 생성기가 만들었지만 검산(주로 '숫자가 깔끔한가' 검사)에 걸려 버리고 새로 만든 문항 수입니다.

검산 항목:

| 유형 | 확인하는 것 |
|---|---|
| A 직교여공간 | W 의 생성벡터와 W⊥ 기저의 내적이 모두 0, W⊥ 기저가 일차독립, dim W + dim W⊥ = n |
| B 정사영 | proj + perp = v, perp 가 W 의 모든 기저벡터와 수직, proj ∈ W |
| C 그램-슈미트 | 결과 벡터들이 서로 직교, 각 k 에 대해 span(x₁..x_k) = span(v₁..v_k), QᵀQ = I |
| D QR | A = QR, QᵀQ = I, R 이 상삼각이고 대각성분이 양수 |
| E 직교대각화 | A 대칭, PᵀP = I, PᵀAP = D, D 의 대각성분 = 특성다항식의 근(중복도 포함) |
| F 스펙트럼 분해 | Σλᵢqᵢqᵢᵀ = A, 각 qᵢqᵢᵀ 가 정사영행렬(P² = P, Pᵀ = P), PᵢPⱼ = 0, (2×2) Aⁿ 공식이 n = 1..6 에서 실제 Aⁿ 과 같음 |
| G 역문제 | A 대칭·정수행렬, 모든 고유쌍에 대해 Au = λu, 고윳값의 중복도 일치 |
| H 참/거짓 | 해설에 반례가 있으면 그 반례를 SymPy 로 다시 계산 |
| 공통 | 답에 나오는 제곱근은 √2, √3, √5, √6(의 유리수배)뿐, 분모 ≤ 36 |

## 문제 유형

| 기호 | 유형 | 변형 |
|---|---|---|
| A | 직교여공간 | ℝ³/ℝ⁴ 에서 W = span{…} 일 때 W⊥ 의 기저(W⊥ = Null A), W 를 연립방정식으로 줄 때 W 와 W⊥ 의 기저 |
| B | 정사영과 직교분해 | ℝ³ 평면 위로의 분해와 점-평면 거리, 직교기저(공식 직접 사용), 직교하지 않는 기저(정규방정식 BᵀBx̂ = Bᵀv) |
| C | 그램-슈미트 | ℝ³, ℝ⁴ 의 벡터 2~3개 → 직교기저, 정규직교기저 |
| D | QR 분해 | 3×2, 4×3 행렬 |
| E | 직교대각화 | 2×2, 3×3 서로 다른 고윳값, 3×3 중근(중근의 고유공간에서만 그램-슈미트가 필요한 경우) |
| F | 스펙트럼 분해 | A = Σλᵢqᵢqᵢᵀ (2×2 는 Aⁿ 계산까지, 3×3, 3×3 중근) |
| G | 역문제 | 고윳값과 일부 고유벡터 → A. 빠진 고유벡터는 직교성(2차원은 수직 벡터, 3차원은 외적)으로 찾음. 중근이면 A = λ₁I + (λ₂−λ₁)uuᵀ/(u·u) |
| H | 참/거짓 | 24개 고정 문항 은행에서 섞어서 출제. 거짓이면 반례 해설 |

### 숫자가 깔끔하게 나오는 원리

- **직교 정수벡터에서 거꾸로 만들기**: 길이의 제곱이 `k²·r` (r ∈ {1,2,3,5,6}) 인 서로 직교하는 정수벡터(예: (1,1,1), (1,−1,0), (1,1,−2) / (1,2,2), (2,1,−2), (2,−2,1))를 먼저 고릅니다. 그래서 정규화하면 √2, √3, √5, √6 정도만 나옵니다.
- **대칭행렬**: A = Σ λᵢ uᵢuᵢᵀ/(uᵢ·uᵢ) 에 정수 고윳값을 넣고, 결과가 정수행렬이고 성분이 작을 때만 채택합니다. 중근 행렬은 성분이 모두 0이 아닌 u 를 써서, 고유공간의 기본 기저(행간소화에서 나온 것)가 직교하지 않도록 합니다. 그러면 그 고유공간에서만 그램-슈미트가 필요합니다.
- **그램-슈미트/QR 입력**: 직교 정수기저 w₁, w₂, … 에 상삼각 변환(x₂ = d·w₂ + c·w₁ 등, d, c 는 1/2, 1/3 같은 간단한 분수)을 걸고 x 가 정수일 때만 씁니다. 그래서 중간 계산엔 분수가 나오지만 정리하면 깔끔한 정수벡터가 됩니다.
- **정사영**: v = (W 의 원소) + (W⊥ 의 원소) 로 만들어서 proj 와 perp 가 정수벡터가 되게 합니다.
- **풀이는 SymPy 가 행렬에서 직접 다시 계산**합니다(특성다항식, 행간소화, 영공간, 그램-슈미트). 생성에 쓴 고유벡터를 그대로 베끼지 않습니다.

### 답이 여러 가지일 수 있는 경우

기저(W⊥, 고유공간)는 유일하지 않습니다. 고유벡터의 부호·순서와 중근 고유공간의 정규직교기저도 고르기 나름이라, 풀이와 다른 P 도 정답일 수 있습니다. 자기 답은 PᵀP = I, PᵀAP = D 를 직접 확인하세요. 스펙트럼 분해에서 같은 고윳값끼리 묶은 항의 합(고유공간 위로의 정사영)은 기저 선택과 상관없이 같습니다.

## 새 문제집 만들기 / 바꾸기

1. 다른 시드로 만들기: `python generator.py --seed 2026 --count 48 --sets 3`
2. `python verify.py --seeds 2026-2028` 로 검산합니다. `--check-html --html-seed 2026` 을 붙이면 저장된 HTML 과 생성기 출력이 같은지도 확인합니다.
3. 참/거짓 문항은 `generator.py` 의 `TF_BANK` 목록에 `dict(s=명제, a=참/거짓, e=해설, c=반례 확인 함수(선택))` 형식으로 추가합니다.
4. 유형별 변형 비율은 `COMPLEMENT_VARIANTS`, `PROJECTION_VARIANTS`, `GS_VARIANTS`, `QR_VARIANTS`, `DIAG_VARIANTS`, `SPECTRAL_VARIANTS`, `INVERSE_VARIANTS` 목록에서 바꿀 수 있습니다.

## 알려진 한계 / 메모

- 수식은 MathJax 3.2.2(cdnjs, `tex-mml-chtml.min.js`)로 그립니다. 작업 환경에서는 cdnjs 에 접속할 수 없어서, 같은 버전의 npm 패키지(`mathjax@3.2.2`)를 로컬에 받아 렌더링을 확인했습니다(수식 오류 0개, 휴대폰 폭 390px 에서 가로 스크롤 없음). 아주 긴 행렬식은 휴대폰에서 그 수식만 가로로 스크롤됩니다.
- 참/거짓 문항의 참/거짓 판정 자체는 사람이 작성한 것입니다. 반례가 있는 문항만 SymPy 로 반례를 다시 계산합니다.
- 깔끔함 검사(√2, √3, √5, √6, 분모 ≤ 36)는 일부러 엄격하게 잡았습니다. 고유공간 그램-슈미트에서 길이의 제곱이 45 처럼 커지는 경우 등이 걸러지며, 그때는 자동으로 다른 문항을 새로 만듭니다.
